# 구성원 운영 가이드

이 문서는 오토원워크에서 구성원 추가, 수정, 삭제, 비밀번호 초기화를 처리하는 운영 절차다.

## 접근 위치

- 메뉴: 어드민 > 구성원 관리
- URL: `/admin/employees.html`
- 접근 권한: 관리자 또는 대표 권한 계정

권한이 없는 계정은 어드민 메뉴가 보이지 않거나 접근 시 홈으로 이동된다.

## 구성원 추가

1. 어드민 > 구성원 관리로 이동한다.
2. 우측 상단 `구성원 추가` 버튼을 누른다.
3. 아이디를 입력한다.
   - 아이디는 로그인 ID가 된다.
   - 메일주소는 `아이디@autonecar.kr`로 생성된다.
4. 이름을 입력한다.
5. 부서를 선택한다.
   - 부서가 없으면 먼저 `부서 관리`에서 추가한다.
6. 직책, 직위, 사용자 유형을 선택한다.
7. 휴대전화, 내선번호를 입력한다.
   - 내선번호가 없으면 `없음`을 체크한다.
8. 생년월일을 선택한다.
9. 입사일을 선택한다.
10. 근무시간을 선택한다.
    - 일부 부서는 요일별 근무시간이 자동 적용된다.
11. `추가하기`를 누른다.
12. 완료 알림에 표시되는 메일주소와 임시 비밀번호를 사용자에게 전달한다.

현재 기본 임시 비밀번호는 `1234`다.

## 신규 구성원 첫 로그인

1. 신규 구성원은 아이디와 임시 비밀번호 `1234`로 로그인한다.
2. 임시 비밀번호 상태이면 비밀번호 변경 화면으로 이동한다.
3. 새 비밀번호를 입력한다.
4. 변경 완료 후 다시 로그인하거나 홈으로 이동한다.

비밀번호는 최소 4자 이상이어야 한다.

## 구성원 정보 수정

1. 구성원 관리 목록에서 대상 구성원을 클릭한다.
2. 구성원 설정 모달에서 정보를 수정한다.
3. `수정완료`를 누른다.

수정 가능한 항목:

- 이름
- 부서
- 직책
- 직위
- 사용자 유형
- 휴대전화
- 내선번호
- 생년월일
- 입사일
- 근무시간

대표/관리자 유형은 일부 근태 관련 입력 항목이 숨겨질 수 있다.

## 비밀번호 초기화

1. 구성원 관리 목록에서 대상 구성원을 클릭한다.
2. 구성원 설정 모달에서 `비밀번호 초기화`를 누른다.
3. 확인창에서 초기화를 승인한다.
4. 사용자에게 임시 비밀번호 `1234`를 전달한다.
5. 사용자는 다음 로그인 시 비밀번호 변경을 진행한다.

비밀번호 초기화는 서버에서 임시 비밀번호 플래그를 다시 켠다. 사용자가 새 비밀번호로 변경하면 플래그가 해제된다.

## 구성원 삭제

1. 구성원 관리 목록에서 대상 구성원을 클릭한다.
2. 구성원 설정 모달에서 `삭제`를 누른다.
3. 확인창에서 삭제를 승인한다.

주의:

- 관리자 기본 계정은 삭제 버튼이 숨겨진다.
- 삭제 전 D1/KV 백업을 권장한다.
- 삭제된 사용자의 과거 메일, 결재 문서, 채팅 메시지는 별도 데이터로 남을 수 있다.

## 부서 관리

1. 구성원 관리 상단의 `부서 관리`를 누른다.
2. 부서명을 입력하고 `추가`를 누른다.
3. 기존 부서는 `부서명 변경` 또는 `삭제`로 관리한다.

주의:

- 직원이 소속된 부서를 삭제하면 직원의 부서 연결이 해제될 수 있다.
- 부서명 변경은 직원 목록, 캘린더, 팀게시판 표시에도 영향을 줄 수 있다.

## 사용자 유형 기준

| 유형 | 값 | 용도 |
| --- | --- | --- |
| 임직원 | `staff` | 일반 사용자 |
| 대표(관리자) | `admin` | 어드민 접근 및 관리 권한 |

현재 UI에서는 대표(관리자)가 `admin` 권한으로 저장된다. 내부 권한 헬퍼는 대표/관리자 계정을 실행 권한이 있는 사용자로 처리한다.

## 직원번호

직원번호는 서버에서 자동 생성된다.

- 앞 2자리: 현재 연도 기준 prefix
- 뒤 4자리: 순번

예: `260001`

운영자가 직접 입력하지 않는다.

## 백업 권장 시점

아래 작업 전에는 백업을 권장한다.

- 구성원 대량 추가
- 부서 대량 변경
- 대표/관리자 권한 변경
- 구성원 삭제
- 운영 DB 직접 수정

백업 방법은 `docs/GROUPWARE_BACKUP_RESTORE.md`를 따른다.

## 문제 해결

### 신규 사용자가 로그인하지 못함

- 아이디가 정확한지 확인한다.
- 임시 비밀번호 `1234`로 시도한다.
- 비밀번호 초기화를 다시 실행한다.
- 직원 목록에 계정이 있는지 확인한다.

### 비밀번호 변경 화면에서 막힘

- 새 비밀번호가 4자 이상인지 확인한다.
- 브라우저 캐시를 새로고침한다.
- 관리자에서 비밀번호 초기화를 다시 실행한다.

### 어드민 메뉴가 보이지 않음

- 사용자 유형이 대표(관리자)인지 확인한다.
- 로그아웃 후 다시 로그인한다.
- `userRole`이 `admin`으로 저장되었는지 확인한다.

### 부서가 선택 목록에 없음

- `부서 관리`에서 부서를 먼저 추가한다.
- 추가 후 구성원 추가/설정 모달을 다시 연다.
