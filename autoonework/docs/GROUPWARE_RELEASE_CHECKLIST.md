이 문서는 PWA 운영 전 마지막 점검용이다. 체크는 실제 브라우저/PWA 설치 앱에서 진행한다.

## 2. 배포 전 준비

- [ ] `scripts/release.sh` 실행 옵션을 정했다.
- [ ] `node scripts/preflight-check.mjs` 자동 점검을 통과했다.
- [ ] `wrangler.toml`의 D1/KV/R2 바인딩이 운영 리소스를 가리킨다.
- [ ] `layout/config.js`의 기본 API 주소가 운영 Worker를 가리킨다.
- [ ] 앱 아이콘과 기본 브랜딩이 `오토원워크`에 맞다.
- [ ] 배포용 정적 자산 버전이 이번 배포 버전으로 올라가 있다.
- [ ] 배포 전 D1/KV 백업을 완료했다.
- [ ] `node scripts/verify-backup.mjs <백업폴더>` 검증을 통과했다.
- [ ] 주요 테스트 계정 비밀번호를 알고 있다.

## 3. 설치/실행

- [ ] 기존 설치 앱을 삭제한다.
- [ ] 브라우저 캐시 또는 사이트 데이터를 정리한다.
- [ ] 브라우저에서 앱을 연다.
- [ ] 설치 또는 바로가기 동작이 정상이다.
- [ ] 실행 시 앱 이름이 `오토원워크`로 보인다.
- [ ] 앱 아이콘이 오토원워크 아이콘으로 보인다.
- [ ] PC에서 최초 실행 시 창 폭이 약 1400px로 열린다.
- [ ] PC에서 창 폭이 1000px 이하로 줄어들지 않는다.
- [ ] 재실행해도 상단/사이드바/본문 레이아웃이 깨지지 않는다.

- [ ] 로그인 페이지가 정상 표시된다.
- [ ] 비밀번호 찾기 페이지가 정상 표시된다.
- [ ] 비밀번호 변경 페이지가 정상 표시된다.
- [ ] 홈 대시보드가 정상 표시된다.
- [ ] 상단 사용자 정보가 정상 표시된다.
- [ ] 좌측 앱 메뉴가 정상 표시된다.
- [ ] 모바일 하단 메뉴가 정상 표시된다.
- [ ] 테이블이 좁은 창에서 가로 스크롤로 표시된다.

## 5. 계정/권한별 메뉴

### 일반 직원

- [ ] 어드민 메뉴가 보이지 않는다.
- [ ] 출퇴근 메뉴가 보인다.
- [ ] 전자결재 메뉴가 보인다.
- [ ] 메일/채팅/캘린더/게시판 메뉴가 보인다.
- [ ] 공지사항 작성 버튼이 보이지 않는다.
- [ ] 리소스센터 업로드 버튼이 보이지 않는다.

### 관리자

- [ ] 어드민 메뉴가 보인다.
- [ ] 직원 관리 페이지에 접근 가능하다.
- [ ] 근태 관리 페이지에 접근 가능하다.
- [ ] 휴가 관리 페이지에 접근 가능하다.
- [ ] 공지사항 작성/수정/삭제가 가능하다.
- [ ] 리소스센터 업로드/수정/삭제가 가능하다.

### 대표/임원

- [ ] 어드민 메뉴 접근 정책이 의도대로 동작한다.
- [ ] 출퇴근 메뉴 숨김 정책이 의도대로 동작한다.
- [ ] 전사 일정 등록/수정/삭제가 가능하다.
- [ ] 팀 캘린더 전체 조회가 가능하다.
- [ ] 공지사항/리소스센터 관리 권한이 정상이다.

### 공용/시스템 계정

- [ ] 허용된 메뉴만 보인다.
- [ ] 채팅 메뉴가 숨겨진다.
- [ ] 전자결재/팀게시판 등 제한 메뉴가 숨겨진다.

- [ ] 임시보관함 목록이 표시된다.

- [ ] 대화방 목록이 먼저 표시된다.

- [ ] 대화방 진입 시 메시지가 표시된다.
- [ ] 새 메시지 발송이 정상 동작한다.
- [ ] 이미지/파일 첨부가 정상 동작한다.
- [ ] 읽음 처리와 미읽음 배지가 정상 동작한다.
- [ ] 채팅방 나가기/초대/그룹 설정이 정상 동작한다.
- [ ] 앱 재실행 후 대화방 목록이 캐시로 빠르게 표시된다.

- [ ] 관리자 근태 현황이 정상 표시된다.
- [ ] 관리자 휴가 현황이 정상 표시된다.
- [ ] 추가 연차 저장이 정상 동작한다.

- [ ] 구성원 생일 표시가 정상 동작한다.

- [ ] 리소스센터 목록이 정상 표시된다.

- [ ] 클라우드 파일 업로드가 정상 동작한다.

## 12. 오프라인/캐시

- [ ] 새 배포 후 새 서비스워커가 설치된다.
- [ ] 새로고침 후 최신 JS/CSS가 적용된다.
- [ ] 기존 설치 앱에서 캐시가 갱신된다.
- [ ] 캐시가 갱신되지 않으면 앱 삭제 후 재설치 절차로 해결된다.
- [ ] `/offline.html` 안내 화면이 정상 표시된다.
- [ ] 네트워크 오류 시 사용자에게 치명적 빈 화면이 표시되지 않는다.

## 13. 성능 체감

- [ ] 채팅 첫 진입이 과하게 느리지 않다.
- [ ] 메일 목록 전환이 과하게 느리지 않다.
- [ ] 전자결재 목록/상세 진입이 과하게 느리지 않다.
- [ ] 좁은 창에서 테이블 레이아웃이 깨지지 않는다.
